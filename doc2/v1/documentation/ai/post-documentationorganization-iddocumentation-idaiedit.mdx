Takes markdown content and a prompt, returns modified content with diff

<Video src="https://www.youtube.com/watch?v=EqafUcDSekc" provider="youtube" />

<Endpoint method="POST" path="/documentation/{organization_id}/{documentation_id}/ai/edit" />

## Path Parameters

<Param path="organization_id" type="string" required>
  Organization ID
</Param>
<Param path="documentation_id" type="string" required>
  Documentation ID
</Param>
## Request Body

Edit request

**Required**

<Param path="content" type="string" />
<Param path="prompt" type="string" required />
**Example:**

```json

  "content": "string",
  "prompt": "string"
}
```
