Returns paginated organizations enriched with owner info, plan and documentation status counters. Optional filters: plan_filter (free|paid), plan_status (csv), doc_state (csv: has_failed,has_pending,has_processing,no_docs), min_docs.

<Endpoint method="GET" path="/v1/admin/customers" />

## Authentication

**API Key** (`BearerAuth`)
- Header: `Authorization`

## Responses

<Response status="200">
  OK
</Response>

**Response Fields:**

- `items` (object[])
- `page` (integer)
- `page_size` (integer)
- `total` (integer)
- `total_pages` (integer)

**Example:**

```json
{
  "items": [
    {
      "created_at": "string",
      "doc_count": 0,
      "doc_failed": 0,
      "doc_generated": 0,
      "doc_pending": 0,
      "doc_processing": 0,
      "doc_published": 0,
      "is_lifetime": true,
      "organization_id": "string",
      "organization_name": "string"
    }
  ],
  "page": 0,
  "page_size": 0,
  "total": 0,
  "total_pages": 0
}
```
