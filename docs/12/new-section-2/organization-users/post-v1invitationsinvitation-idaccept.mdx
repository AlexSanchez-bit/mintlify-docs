Accepts a pending organization invitation targeted at the authenticated user's email.

<Endpoint method="POST" path="/v1/invitations/{invitation_id}/accept" />

## Authentication

**API Key** (`BearerAuth`)
- Header: `Authorization`

## Path Parameters

<ParamField path="invitation_id" type="string" required>
  Invitation ID
</ParamField>
