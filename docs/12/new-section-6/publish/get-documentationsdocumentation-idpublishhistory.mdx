Returns the paginated list of publish events for a documentation

<Endpoint method="GET" path="/documentations/{documentation_id}/publish/history" />

## Authentication

**API Key** (`BearerAuth`)
- Header: `Authorization`

## Path Parameters

<ParamField path="documentation_id" type="string" required>
  Documentation ID
</ParamField>

## Query Parameters

<ParamField path="page" type="integer">
  Page number (default 1)
</ParamField>

<ParamField path="page_size" type="integer">
  Page size (default 20, max 100)
</ParamField>

## Responses

<Response status="200">
  Publish history
</Response>

**Response Fields:**

- `items` (object[])
- `page` (integer)
- `page_size` (integer)
- `total` (integer)
- `total_pages` (integer)
