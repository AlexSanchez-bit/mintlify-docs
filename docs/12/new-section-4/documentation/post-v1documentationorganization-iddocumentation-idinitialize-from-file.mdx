Takes Resource(file) IDs previously uploaded via /file-resources,

<Endpoint method="POST" path="/v1/documentation/{organization_id}/{documentation_id}/initialize-from-file" />

## Authentication

**API Key** (`BearerAuth`)
- Header: `Authorization`

## Path Parameters

<ParamField path="organization_id" type="string" required>
  Organization ID
</ParamField>

<ParamField path="documentation_id" type="string" required>
  Documentation ID
</ParamField>

## Request Body

Resource IDs to ingest

**Required**

<ParamField path="resource_ids" type="string[]" required>
</ParamField>

<ParamField path="section_name" type="string">
</ParamField>

**Example:**

```json
{
  "resource_ids": [
    "string"
  ],
  "section_name": "string"
}
```
